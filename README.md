# 🤖 Resume Screening & Candidate Scoring System

A data-driven NLP system that analyzes and ranks resumes against job descriptions.

## 🛠️ Tech Stack
Python | Pandas | NLTK | Scikit-learn | TF-IDF | Cosine Similarity | Matplotlib | Seaborn | WordCloud

## ✨ Features
- NLP text preprocessing (tokenization, lemmatization, stopword removal)
- TF-IDF vectorization of resumes and job descriptions
- Cosine similarity scoring to rank candidates
- Skill extraction using keyword matching
- Visual outputs: bar chart, heatmap, word cloud

## 📊 Results
- Shortlisted top 3 out of 5 candidates accurately
- Eva (41.84%) → Carol (40.32%) → Alice (36.59%)
