# Resume Screening & Candidate Scoring System

A data-driven web application that analyzes and ranks resumes based on job 
descriptions using NLP techniques and Machine Learning algorithms.

🔗 **Live Demo**: https://resume-screening-system-msu5zdyotgtnylyrvoq9tx.streamlit.app

## 🚀 Features
- Upload resumes and job descriptions for automated screening
- NLP text preprocessing — tokenization, lemmatization, stopword removal
- TF-IDF vectorization and Cosine Similarity scoring
- Automated candidate shortlisting with adjustable threshold slider
- Skill extraction using keyword matching against a curated skills dictionary
- Visual results — ranked bar charts, skills heatmap, and word cloud
- CSV download of screening results
- Interactive web app built with Streamlit

## 🛠️ Tech Stack
- **Language**: Python
- **NLP**: NLTK
- **ML**: Scikit-learn (TF-IDF, Cosine Similarity)
- **Data**: Pandas
- **Visualization**: Matplotlib, Seaborn
- **Web App**: Streamlit
- **Version Control**: GitHub

## ⚙️ How to Run Locally

```bash
git clone https://github.com/Anjali-55555/resume-screening-system
cd resume-screening-system
pip install -r requirements.txt
streamlit run app.py
```
